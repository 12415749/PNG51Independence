# PNG 51st Independence Celebration Website

A self-contained, responsive HTML/CSS/JavaScript celebration page for Papua New Guinea's 51st Independence Anniversary.

## Files

- `index.html` — complete application
- `assets/png-flag.png` — user-provided PNG flag image
- `assets/bird-of-paradise.png` — user-provided Bird of Paradise image

## Run locally

Double-click `index.html`, or use VS Code Live Server.

## Deploy for a WhatsApp link

Because this is a static website, it can be hosted on GitHub Pages, Netlify, Vercel, Cloudflare Pages, or another static host.

After deployment, copy the public HTTPS URL and paste it into your WhatsApp group.

## Important

The website uses the 2026 date of 16 September for the 51st Independence Anniversary and includes historical information about 1973 self-government, 1975 independence and 1975 UN membership.

The "I HATE PNG" button is intentionally playful and moves away from attempted interaction. The "I LOVE PNG" button activates the celebration interface.
